# 05 — خطة التنفيذ بالمراحل

> **قاعدة:** مرحلة واحدة في كل مرة. لا تبدأ التالية قبل اجتياز معايير القبول.
> كل مرحلة تنتهي بشيء **قابل للاستخدام فعليًا**، وليس بكود على الرف.

الترتيب مبني على منطق واحد: **الاستوديو قبل الموقع.**
السبب — أول 20 طلب سيأتون من إنستغرام وواتساب، لا من الموقع. ما تحتاجه فورًا
هو نظام يُنتج القصص بجودة وسرعة، لا صفحة هبوط جميلة بلا قدرة تسليم.

## المخاطر التقنية وكيف نمنعها مبكرًا

| الخطر | المنع |
|---|---|
| عدم ثبات شكل الطفل بين الصفحات | `heroDescriptor` مقفول يُكرَّر حرفيًا + شريط مقارنة + استخدام الغلاف كمرجع |
| العربية تنكسر في PDF | اختبر بلقطة شاشة في المرحلة 3 قبل بناء بقية القوالب |
| تكلفة AI تنفلت | `AiRun` + سقف شهري + cache للـ teaser + سقف يومي منفصل |
| تسريب صور طفل | لا URL عام أبدًا + proxy + AuditLog + حذف مجدول + اختبار E2E للصلاحيات |
| Gotenberg يستهلك الذاكرة | حاوية منفصلة + طابور pdf بـ WithoutOverlapping + `--max-requests` |
| Inertia يضرّ SEO | فعّل Inertia SSR للصفحات العامة في المرحلة 4 — لا تؤجّله |
| المعالج طويل فيهجره العميل | حفظ تلقائي + رابط استكمال + الغلاف الحيّ مبكرًا + قياس التسرب لكل خطوة |
| توسّع النطاق قبل أول عميل | لا تبنِ المرحلة 7 مهما كان الإغراء |
