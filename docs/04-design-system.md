# 04 — نظام التصميم والواجهات

---

## ⚠️ قبل أي شيء

الفريق **أنجز الهوية البصرية والشعار بالفعل**.

**الخطوة الأولى الإلزامية:** استخرج التوكنات من ملفات الهوية الحقيقية
(الشعار، لوحة الألوان، الخطوط) وضعها في `resources/css/app.css` داخل `@theme`.

ما يلي هو **اقتراح احتياطي** يُستخدم فقط إذا لم تتوفر ملفات الهوية، أو كأساس للنقاش.
لو تعارض مع الهوية الفعلية — **الهوية الفعلية تفوز دائمًا**.

---

## أ. الاتجاه البصري المقترح: «سماء الحكايات»

**المنطق:** طيوف = جمع طيف — الخيال، الظلال اللطيفة، ما يُرى قبل النوم.
هذا يقود مباشرة إلى **سماء ليلية دافئة** لا إلى الباستيل الطفولي المكرر
الذي تستخدمه كل صفحة أطفال على إنستغرام.

هذا قرار متعمّد ضد الافتراضي:
- **ليس** خلفية كريمية + خط serif + أكسنت طيني (النمط الافتراضي للذكاء الاصطناعي).
- **ليس** باستيل وردي/سماوي (النمط الافتراضي لمنتجات الأطفال).
- بل: نيلي عميق كخلفية للأقسام السردية، ورق دافئ للأقسام العملية، وذهب كضوء.

### التوكنات

Tailwind v4 — التوكنات تُعرَّف في CSS مباشرة، بلا `tailwind.config.js`:

```css
/* resources/css/app.css */
@import "tailwindcss";

@theme {
  /* الخلفيات */
  --tu-night:      #171438;  /* نيلي عميق — أقسام الحكاية والبطل */
  --tu-night-soft: #241F52;  /* بطاقات على النيلي */
  --tu-paper:      #FFF7EC;  /* ورق دافئ — الأقسام العملية */
  --tu-paper-2:    #F6EBDC;  /* تناوب */
  --tu-white:      #FFFFFF;

  /* الأكسنت */
  --tu-gold:       #FFC24B;  /* الضوء — CTA رئيسي، نجوم، تمييز */
  --tu-gold-deep:  #E9A320;
  --tu-coral:      #FF7A66;  /* دفء ثانوي — شارات، تنبيهات لطيفة */
  --tu-mint:       #5FD3B8;  /* نجاح، تأكيد */

  /* النص */
  --tu-ink:        #1B1733;  /* على الورق */
  --tu-ink-soft:   #5A5478;
  --tu-on-night:   #FFF7EC;
  --tu-on-night-soft: #B6AEDA;

  /* البنية */
  --tu-border:     #E8DCC9;
  --tu-radius:     20px;     /* بطاقات — دائري ودافئ */
  --tu-radius-sm:  12px;
  --tu-radius-pill: 999px;

  --font-display: "Baloo Bhaijaan 2", sans-serif;
  --font-body: "IBM Plex Sans Arabic", sans-serif;
}
```

تُستخدم في JSX كـ `bg-tu-night` و`text-tu-gold` و`font-display` — لا قيم hex في المكوّنات.

**قواعد الاستخدام:**
- الذهب للفعل فقط (CTA، نجمة، تمييز الاسم). لا تملأ به مساحات كبيرة.
- النيلي للحظات السردية: الهيرو، «كيف تعمل»، شهادات، الفوتر.
- الورق للحظات العملية: الباقات، المعالج، الأسئلة، لوحة العميل.
- التبديل بين نيلي وورق يجب أن يكون له **معنى**، لا زخرفة.

### الخطوط

```
عناوين (Display):  Baloo Bhaijaan 2  — عربي مستدير ودود، أوزان 600/800
نص (Body):         IBM Plex Sans Arabic — وضوح عالٍ، أوزان 400/500/600
أرقام وواجهة:      Inter — للأرقام اللاتينية والأكواد فقط

H1  clamp(2rem, 6vw, 4.25rem) / 800 / line-height 1.15
H2  clamp(1.6rem, 4vw, 2.75rem) / 700
H3  clamp(1.25rem, 2.5vw, 1.75rem) / 600
Body 16–18px / 400 / line-height 1.9  ← العربية تحتاج ارتفاع سطر أكبر
Small 14px / 400 / --tu-ink-soft
```

**تنبيه عربي:** `line-height: 1.9` للنص و`1.15` للعناوين. الافتراضات اللاتينية
تُنتج نصًا عربيًا مضغوطًا وغير مقروء.

### العنصر المميّز (Signature)

**«الغلاف الحيّ»** — في الهيرو، كتاب مفتوح مرسوم يحوم فوق سماء نجوم، وفيه
حقل إدخال واحد: *اكتب اسم طفلك*. بمجرد الكتابة، يُكتب الاسم على الغلاف
بخط اليد الذهبي، وتضيء نجمة، ويتحرك عنوان القصة.

هذا هو الشيء الوحيد الذي نصرف عليه جرأتنا. كل شيء آخر هادئ ومنضبط.
والحقل نفسه هو الخطوة 1 من `/create` — فالهيرو ليس زخرفة، هو بداية الطلب.

### الحركة

- تسلسل تحميل واحد للهيرو (نجوم تظهر → الكتاب يرتفع → الحقل يضيء).
- كشف عند التمرير لبطاقات القصص فقط.
- micro-interaction على أزرار CTA (ارتفاع خفيف + توهج ذهبي).
- **احترم `prefers-reduced-motion`** — أوقف كل شيء عداه الظهور.
- ممنوع: parallax ثقيل، جسيمات متحركة دائمًا، عدّادات متحركة.

## ج. مكوّنات عالم طيوف

كلها في `resources/js/components/site/`:

| المكوّن | الاستخدام |
|---|---|
| `<LiveCover name>` | الغلاف الحيّ — الهيرو والمعالج |
| `<StarField>` | خلفية نجوم SVG خفيفة (CSS فقط، لا canvas) |
| `<WorldCard>` | بطاقة عالم بصورة وعنوان |
| `<StepTrail>` | مسار الخطوات المرقّم |
| `<TrustStrip>` | شريط الثقة |
| `<PackageCard>` | بطاقة باقة + شارة «الأكثر طلبًا» |
| `<StoryJourney>` | خط رحلة الطلب للعميل (7 مراحل) |
| `<PagePreview>` | معاينة صفحة كتاب بعلامة مائية |
| `<ConsentBox>` | صندوق الموافقة — تصميم واضح وغير مخيف |
| `<EmptyState>` | حالات فارغة بلغة طيوف |

### نبرة النصوص

- قريبة، دافئة، بلا مبالغة. جملة قصيرة.
- الفعل يقول ما سيحدث بالضبط: «أرسِل المعاينة» لا «تأكيد».
- الاسم يبقى ثابتًا في كل الرحلة: زر «اعتمد القصة» → إشعار «تم اعتماد القصة».
- الأخطاء لا تعتذر ولا تُبهم: «الصورة أقل من الوضوح المطلوب. جرّب صورة بإضاءة أفضل.»
- الحالة الفارغة دعوة: «لسّه ما بدأت حكاية. نبدأ؟»

**نصوص جاهزة** (استخدمها كما هي):

```
H1:        اجعل طفلك بطل الحكاية
Sub:       قصة مصورة باسمه وصفاته واهتماماته، مطبوعة ومغلّفة وتصل إلى بيتك.
CTA:       ابدأ قصة طفلك
الثقة:     صورك محمية · معاينة قبل الطباعة · تعديل مجاني · توصيل للبيت
الأمان:    صور طفلك تُستخدم لصناعة قصته فقط — ولا تُنشر أبدًا بدون إذنك المكتوب،
           وتُحذف تلقائيًا بعد ٣٠ يومًا من التسليم.
الفوتر:    طفلك بطل الحكاية.
```

## د. الاستوديو الإداري — Metronic

**اقرأ skill `metronic-dashboard` حرفيًا.** مكوّناته في `resources/js/components/studio/`
وتوكناته في `resources/css/studio.css`. الملخص الملزم:

```css
:root {
  --bg-page: #F2F2F4;  --bg-white: #FFFFFF;
  --bg-hover: #F5F5F7; --bg-active: #F0F0F3;
  --text-900: #0D0D0D; --text-700: #1A1A1A;
  --text-400: #6B6B80; --text-200: #A0A0B0;
  --border: #E8E8EE;   --border-input: #DCDCE0;
  --btn-primary: #000000;              /* أسود — ليس أزرق */
  --dark-sidebar: #14151A;
  --dark-sidebar-active: #2A2B38;
}
```

- التخطيط: **Layout A** — شريط أيقونات 60px داكن + قائمة نصية 230px بيضاء + محتوى.
- زر primary أسود. الأزرق للروابط فقط.
- البطاقات: بيضاء، `rounded-lg` (8px)، حد `#E8E8EE`، بدون ظل.
- نص الجسم 14px، عناوين الصفحات 20px/600، تسميات الأقسام 11px uppercase.
- `dir="rtl"` + `ms-*`/`me-*`.
- الخط: Inter للاتيني + IBM Plex Sans Arabic للعربي.

### شارات الحالة (خريطة ثابتة)

| الحالة | الخلفية | النص |
|---|---|---|
| `NEW`, `DATA_REVIEW` | `#E0E7FF` | `#4338CA` |
| `WRITING`, `STORY_REVIEW`, `CHARACTER_SETUP` | `#FEF9C3` | `#A16207` |
| `PROMPTS_READY`, `ILLUSTRATING`, `IMAGE_REVIEW` | `#FFEDD5` | `#C2410C` |
| `BOOK_LAYOUT`, `QC`, `PREVIEW_SENT` | `#DBEAFE` | `#1D4ED8` |
| `APPROVED` → `SHIPPED` | `#DCFCE7` | `#16A34A` |
| `ON_HOLD`, `REVISION_REQUESTED` | `#FEE2E2` | `#DC2626` |
| `COMPLETED` | `#F0F0F3` | `#3D3D50` |

**استخدم نفس الخريطة في لوحة العميل** لكن بألوان طيوف (ذهب/نعناع/مرجاني).

### قواعد كثافة الاستوديو

- الجدول هو العرض الافتراضي. Kanban اختياري وليس العكس.
- كل صفحة طلب تفتح على التبويب الأنسب لحالتها الحالية، لا على «نظرة عامة» دائمًا.
- اختصارات لوحة المفاتيح: `⌘K` بحث، `G+O` الطلبات، `G+T` المهام، `C` نسخ برومبت.
- كل جدول: بحث + فلتر حالة + فلتر مسند إليه + ترتيب + ترقيم صفحات من الخادم.

## هـ. قوالب صفحات الكتاب (PDF)

`resources/views/book/` — **Blade وليس React**. الكتاب صفحة HTML ثابتة يفتحها
Gotenberg عبر رابط موقّع فيصيّرها PDF. لا Inertia ولا JS هنا سوى سطر
`window.__BOOK_READY__ = true` بعد تحميل كل الصور.

```
resources/views/book/
├── render.blade.php            # الغلاف + كل الصفحات + الظهر
└── templates/
    ├── text-bottom.blade.php
    ├── text-top.blade.php
    ├── text-side.blade.php
    ├── full-bleed-caption.blade.php
    ├── cover.blade.php
    └── dedication.blade.php
```

CSS الطباعة في `resources/css/book.css` — يُبنى منفصلًا عن `app.css`.

```
المقاس:        21×21 سم (مربع — الأنسب للأطفال وأرخص طباعة)
Bleed:         3mm على كل جانب
Safe margin:   10mm من الحافة
Gutter:        12mm عند التجليد
الدقة:         صور 300dpi عند المقاس النهائي (≥ 2480px للصفحة)
```

### القوالب

| القالب | الوصف |
|---|---|
| `text-bottom` | صورة كاملة + شريط نص شفاف أسفل |
| `text-top` | نفسه أعلى |
| `text-side` | صورة نصف + نص نصف |
| `full-bleed-caption` | صورة كاملة + جملة واحدة داخل صندوق ذهبي |
| `cover` | الغلاف: عنوان + اسم الطفل بخط اليد الذهبي |
| `dedication` | صفحة الإهداء — خلفية ورق + نص متوسط |

### قواعد

- النص لا يوضع فوق تفاصيل الصورة — استخدم `textSafeArea` من البرومبت.
- تباين النص على الصورة ≥ 4.5:1 (استخدم شريطًا شبه شفاف عند الحاجة).
- خط الكتاب أكبر من خط الويب: 3–5 سنوات = 22–26pt، 6–8 = 18–20pt، 9–10 = 16–18pt.
- المعاينة: 100dpi + علامة مائية «معاينة طيوف» متكررة بشفافية 8%.
- ملف الطباعة: بدون علامة مائية + علامات قص + تحويل CMYK اختياري عبر Ghostscript.
- الخطوط تُخدم من `public/fonts` عبر `@font-face` بملفات محلية — **لا CDN**،
  لأن Gotenberg قد يفشل في جلبها فينهار الشكل العربي بصمت.

## و. إمكانية الوصول

- تباين ≥ 4.5:1 لكل نص. الذهب على النيلي يمر؛ الذهب على الأبيض **لا يمر** —
  لا تستخدمه لنص على خلفية فاتحة.
- focus مرئي دائمًا (حلقة ذهبية 2px).
- كل صورة `alt` بالعربية.
- المعالج قابل للتنقل بالكيبورد بالكامل.
- لا تعتمد على اللون وحده لنقل الحالة — أضف أيقونة أو نصًا.
